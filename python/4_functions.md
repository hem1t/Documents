# Functions

Function are reusable block of code, which can be called with or without parameters to perform an action and maybe return a value.

Structure of a function:
```python
def function_name(parameters):
    # Body of statements
    # Optional return

# calling function
function_name(arguments)
```

**Default Value**

**Assigning Type (Typing)**

**Keyword Parameter (Named Parameters)**
