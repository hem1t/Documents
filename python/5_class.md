###### Inheritance
(Directly copied from Brave AI)
Single Inheritance: One child class derives from one parent class. 
Multiple Inheritance: One child class derives from multiple parent classes. 
Multilevel Inheritance: A class inherits from a derived class, forming a hierarchy (e.g., Grandparent → Parent → Child). 
Hierarchical Inheritance: Multiple child classes inherit from the same single parent class. 
Hybrid Inheritance: A combination of any two or more of the above inheritance structures.
