# ToBeNoted

## **Best Practices**
1. Keep qualitative data as `text`. Like, postal codes, phone numbers, IDs.

## **Caveats**
1. Numbers stored as `text` will be treated as zero in excel.
2. Spelling mistakes makes data treated differently. Like ("Electronics", "electronics", "elctrnics").

## **Note**
1. Numbers formatted as text in excel show green triangle, use (') apostrophe to present a number as text ('00023)
2. Use Currency format in Home Tab to add currency symbol with a Number cell.
3. Currency and Accounting, have difference in the position of currency symbol placement.
4. Cell truncation: `###` when cell content is bigger than the view, it shows (###). The data well and is there, click to view it or elongate the cell view.
