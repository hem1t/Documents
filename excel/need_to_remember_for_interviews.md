# Need to remember for interviews

## Data types
1. Quantitative (Numerical)
   * Discrete => Countable data like Age, Products in Store
   * Continuous => Numbers with Decimal, like Height.

2. Qualitative (Categorical)
   * Nominal => Non-number data. like Country, Payment Method.
   * Ordinal => Non-number data with meaning that can be ordered. like Rating(low, medium, high), Education level.



## Excel Components
| **Component**        | **What is?**                                                                                  |
|----------------------|-----------------------------------------------------------------------------------------------|
| Workbook             | The excel file.                                                                               |
| Worksheet            | A single page made Columns and Rows                                                           |
| Cell                 | Intersection of Columns and Rows. Can be addressed combining  (CellName, RowName). Ex: A1, B2 |
| The Ribbon (Toolbar) | Contains tools for formatting, formulas, data operations and etc.                             |
| Formula Bar          | Field to see and edit the content cells, resides between the ribbon and the worksheet cells   |
