# Power BI

**(SSBI)Self-Service BI**
Business Intelligence tools which allow non-technical users to perform analysis independently instead of relying on IT or data specialists.

**Business Intelligence**
Technology-driven process to provide actionable-insight, over business data. 

| **Descriptive Analysis**  | _"What happened"_    |
| **Prescriptive Analysis** | _"What will happen"_ |


_Power BI_ extends Excel.
Excel is the backbone of _Power BI_.

#### Excel to Power BI
| **Excel**          | **Power BI**             |
|--------------------|--------------------------|
| 1M rows            | M-Billion rows           |
| Basic Visual       | rich,interactive visuals |
| File-based sharing | Cloud-based sharing      |

#### Flow in Power BI
1. Data Import
2. Data Transformation
3. Data Modeling
4. Data Visualization
5. Publishing

#### Components of Power BI
1. Power BI Desktop
2. Power BI Service
3. Power BI Report Server
4. Power BI Mobile

#### Building blocks of Power BI
_DATASET_ Collected data from different sources.
_REPORT_ Interactive pages with charts and tables.
_DASHBOARD_ A single-page view showing key-metrics.
_TILES_ Individual visuals on dashboards.
_WORKSPACES_ Shared space for team to create, manage, and publish.
