# Power BI UI

###### Ribbons
1. Home
   
2. Insert
   Provides options for inserting elements Page, Visual, AI Visual, Elements(Text, Button, Image) and Sparkline.

3. Modeling
   Here we have data manipulation tools.

4. View
   Contains options to modify page looks, by using themes or other page options.

5. Optimize
   Performance analysis options.

6. Help

###### Panes
1. **Filter**
   Options to apply filters on data.
   Filters can be applied to either on Graph / Page / All Pages.

2. **Visualisation**
   List of visuals to use.

3. **Data**
   List of Tables of data.


###### Views
1. **Report View**
   Our main view where all visuals are created.

2. **Table View**
   We can here view, clean and transform data.

3. **Modeling View**
   For creating relationships between tables.
   
4. **DAX View**
   To write DAX queries.
